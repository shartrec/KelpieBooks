The user management screen allows you to add, edit, and remove users from your organization.

{% screenshot() %}
![User List Screenshot](../../screenshots/admin/user-list.png)
{% end %}

## Adding a User

To add a new user, click the "Add User" button. This will open a modal where you can enter the user's details.

{% screenshot() %}
![Add User Screenshot](../../screenshots/admin/add-user.png)
{% end %}

## Editing a User

To edit an existing user, click the edit icon next to the user in the list. This will open a modal where you can update the user's details.

{% screenshot() %}
![Edit User Screenshot](../../screenshots/admin/edit-user.png)
{% end %}

## Deleting a User

To delete a user, click the delete icon next to the user in the list. You will be asked to confirm the deletion.
