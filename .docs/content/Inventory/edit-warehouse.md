# Adding and Editing Warehouses

The **Warehouse Modal** dialog allows you to add a new warehouse or modify the details of an existing warehouse in your inventory system.

You can open this dialog from the main [Warehouse List](../warehouse-list/) page by:
- Clicking the **Add Warehouse** button at the top of the table to create a new warehouse.
- Clicking the **Edit** (pencil icon) button in the "Actions" column for an existing warehouse.

{{< screenshot src="../../screenshots/inventory/edit-warehouse.png" alt="Edit Warehouse Details Screenshot" />}}

## Warehouse Fields

When creating or editing a warehouse, configure the following fields in the modal form:

- **Warehouse Code**: A unique code used to identify the warehouse across system transactions and location hierarchy mappings (e.g., `AUS_NSW_Sth`).
- **Warehouse Name**: The descriptive display name of the warehouse facility (e.g., `Berrima-A bulk store`).
- **Active tracking**: A checkbox indicating whether the warehouse is active for stock tracking, receiving, and order fulfillment operations.

## Saving Changes

- Click **Save** to submit the form and save the warehouse details.
- Click **Cancel** to close the dialog without saving any changes.
